# Sandbox tonal assets

On 2026-09-28 the user authorized replacing the experimental legacy scales with the current
multifamily generator (0.19.0). The primary seed is #3b82f6, with source-exact Light and adaptive
Dark projection using the balanced default recipe. This is a Kiskadee experiment, not official
Fluent evidence or a claim of final visual approval.

`generated/` preserves the canonical source, manifest, diagnostics, JSON and TypeScript exports.
The preset consumes the generated blue, neutral, green and red families; the remaining families
are retained as generation evidence. Light and Dark each publish subtle, medium and vivid anchors;
Dark is no longer produced by reversing the Light scale. Tests verify promoted data and evidence
hashes. Formatting of promoted TypeScript does not alter its scale data.

Card publishes neutral lowest/low/medium and primary highest canonical surfaces for both themes.
Its primary highest surface uses the vivid anchor. Dropdown has its own recipe using these generated
neutral and primary families, with separate active/selected/disabled presentation. Both components
publish on-subtle and on-vivid entries; the Dropdown list remains a neutral reading surface.

Select keeps its experimental pale surface and persistent blue Rest contour. Its focus ring is
independent. The global radius is rounded. The rebuilt Card catalog supplies Showcase backgrounds
without requiring a substitute from another preset.
