# Preset Package

`@kiskadee/presets` contains the official presets, tokens, and schemas for
Kiskadee, a framework that generates and supports any design system.

This package contains ready-to-use schema presets built on top of
`@kiskadee/core`, including templates like iOS 26, Material Design 3, and more.

## Related Packages

- `@kiskadee/core` - Platform-agnostic schema types and utilities.
- `@kiskadee/web-builder` - Generates CSS from presets.
- `@kiskadee/react-components` - React components using generated CSS.
- `@kiskadee/runtime` - Runtime color calculation for dynamic theming.
