# Legacy Engine Archive

This directory preserves the design notes for the former Tonal Scale Lab engine.
Its distributions, interchangeable profiles, repair passes, and integration
ideas are rejected as the active Kiskadee v1 architecture.

The files remain useful as historical evidence for decisions and regression
colors. They are not current requirements. The canonical Milestone 1 contract
is `docs/definitions/tonal-scale.md`, and the archived source implementation is
under `src/legacy/`.
